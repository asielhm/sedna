Privacidad y permisos

El asistente es un proyecto independiente para completar calificaciones desde Excel. No es un producto oficial de Sedna.

Extensión

El archivo Excel y su vista previa se procesan en memoria dentro de tu navegador. La extensión no solicita contraseñas, no utiliza almacenamiento persistente y no envía el Excel a servidores externos. Cerrá el asistente al terminar.

El permiso scripting permite leer la clase y el período y completar los campos de calificaciones. El permiso de sitio se limita a https://sedna.sanandres.esc.edu.ar/*. No se solicitan permisos de cookies ni acceso a otros sitios. El permiso debugger permite conectar el depurador únicamente a la pestaña de Sedna seleccionada durante la carga, resolver diálogos alert/confirm y desactivar caché y service worker temporalmente. Chrome muestra un aviso mientras está conectado. El código desconecta el depurador al finalizar o fallar.

El guardado se realiza automáticamente después de que el profesor confirma las correspondencias y autoriza todas las hojas del Excel. La extensión pulsa Aceptar por clase y verifica los valores mediante una nueva lectura sin caché; esos datos quedan sujetos al funcionamiento y las políticas del colegio y de Sedna.

Página de descargas

Este sitio no incorpora analítica, cookies propias, publicidad ni formularios. GitHub sirve el sitio y puede recopilar registros técnicos conforme a la política de privacidad de GitHub.

Consultas

Podés informar problemas en el repositorio. No publiques datos de alumnos, calificaciones o credenciales.
